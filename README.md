# lection_marine_ecology_data
Here locates presentation which i prepare for lection in LMSU MRS in dec 2025 and supporting materials, like old pictures, code for visualization, examples of ml etc

In repository i save presentation without videos, here is link to presentation with video:
https://docs.google.com/presentation/d/1sbbSXx_hmkQp5mMATWBwIv8M1v7SntLz/edit?usp=sharing&ouid=118399120068307746440&rtpof=true&sd=true

About folders:
- in 01_support_data i put different support data from open sources or just synthetic, and sometimes intermediate working files
- in 02_pictures most of specific or non very specific visualization for presentation (and 2 separate pictures)
- in 03_old_pictures some old kind of maps and visualizations which i include in presentation
- in 04_ml_proc data for example of habitat mapping with machine learning
- 
About jupyter notebooks:
-  01.0_indexes.ipynb - in this file i put some information about biodiversity and other ecological indexes
-  01.1_example_from_another_lection_united_index.ipynb - notebook from another lection about making united index
-  02.0_visualization.ipynb code for visualizations
-  03.0_CV_fish.ipynb file for processing video with fine-tuned YOLO and some analytic about fish in aquarium
-  03.1_CV_benthos.ipynb file for processing video about benthos recieved using underwater towed camera with fine-tuned YOLO 
-  04.0_hm_near_dania.ipynb file with habitat mapping using different sources of data and ml
